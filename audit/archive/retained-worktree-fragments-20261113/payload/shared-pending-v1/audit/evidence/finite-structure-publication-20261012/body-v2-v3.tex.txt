\section{Step 1: branch encoding}\label{step-1-branch-encoding}

For each branch \(a\subseteq S\),

\[
 \operatorname{encode}(a)=\sum_{u\in a}2^u.
\]

The sum runs over source labels in \(a\). Labels 0, 1 and 2 contribute
bits 1, 2 and 4. Hence the empty branch has mask 0 and the full branch
has mask 7.

Decoding \(m\) selects the labels whose bits are set. For example,
\(5=1+4\) decodes to \(\{0,2\}\). Both codec compositions return their
input. Nonempty branches have nonzero masks. Bitwise AND of the masks of
\(a\) and \(b\) equals the mask of \(a\) exactly when \(a\subseteq b\).
These binary masks encode labels, not binary observed values.

\section{Step 2: derive all 18
families}\label{step-2-derive-all-18-families}

There are seven nonempty branches: three single-label, three two-label
and one three-label branch. Each alone forms a valid family, giving
seven families.

Two-branch families have three cases:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Two single-label branches: three choices.
\item
  Two two-label branches: three choices; distinct equal-sized branches
  are incomparable.
\item
  One of each size: the single label must be absent from the pair. It is
  therefore the complementary label, giving three choices.
\end{enumerate}

The full three-label branch is comparable with every nonempty branch, so
cannot occur in a larger family. The two-branch count is \(3+3+3=9\).

Only two three-branch families work: all three single-label branches, or
all three two-label branches. A mixed triple cannot work. Two
single-label branches exclude every two-label branch, since each pair
contains at least one of those labels. One single-label branch permits
just its complementary pair, not two distinct pairs. This also excludes
any four-branch family. The total is therefore \(7+9+2=18\).

Positions are not lattice order.

\section{Step 3: prove the order in both logical
directions}\label{step-3-prove-the-order-in-both-logical-directions}

For arbitrary families \(A,B\) and a truth pattern
\(q:S\to\{\mathrm{false},\mathrm{true}\}\):

\[
 A\preceq B\iff\forall b\in B\;\exists a\in A:\;a\subseteq b,
 \qquad
 D(A,q)\iff\exists a\in A\;\forall u\in a:\;q(u)=\mathrm{true}.
\]

Here \(a,b\) are branches and \(u\) is a source label. The
correspondence is

\[
 A\preceq B\iff\forall q:\;D(B,q)\Rightarrow D(A,q).
\]

Implication runs from \(B\) to \(A\).

Forward proof:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Assume \(A\preceq B\) and \(D(B,q)\).
\item
  The event supplies \(b\in B\) whose tests are all true.
\item
  The order supplies \(a\in A\) with \(a\subseteq b\).
\item
  Every test in \(a\) is among those true tests.
\item
  Thus \(D(A,q)\).
\end{enumerate}

Reverse proof:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Assume the event implication holds for every \(q\).
\item
  Choose any \(b\in B\).
\item
  Set \(q(u)\) true exactly when \(u\in b\).
\item
  Branch \(b\) makes \(D(B,q)\) true.
\item
  The implication supplies \(a\in A\) with all its tests true.
\item
  The chosen pattern then forces every label of \(a\) into \(b\).
\item
  Thus \(a\subseteq b\). Since \(b\) was arbitrary, \(A\preceq B\).
\end{enumerate}

The proof includes invalid families. For empty \(B\), both sides are
true. An empty branch has a true conjunction. Validity is unnecessary
here.

Reflexivity takes the same branch. Transitivity composes
\(a\subseteq b\subseteq c\). For antisymmetry, \(a'\) denotes another
branch of \(A\). Antisymmetry needs validity: from both orders, each
\(a\in A\) gives \(a'\subseteq b\subseteq a\), with \(a'\in A\),
\(b\in B\). The antichain property forces \(a'=a\), then \(b=a\). This
proves \(A\subseteq B\); symmetry proves \(B\subseteq A\).

\section{Step 4: worked example and matrix
direction}\label{step-4-worked-example-and-matrix-direction}

Let \(A=C_7=\{\{0\},\{1\}\}\) and \(B=C_2=\{\{0,1\}\}\). The branch of
\(B\) contains a branch of \(A\), so \(A\preceq B\). The reverse fails:
\(\{0,1\}\) is not contained in either singleton.

For \(q=(\mathrm{true},\mathrm{false},\mathrm{false})\), \(D(A,q)\) is
true but \(D(B,q)\) is false. Yet for every \(q\), true \(D(B,q)\)
implies true \(D(A,q)\).

A row of \(Z\) is a cumulative position; a column is an atom position:
\(Z_{ij}=1\) exactly when \(C_j\preceq C_i\). Consequently \(Z_{2,7}=1\)
and \(Z_{7,2}=0\).

\section{Application meaning}\label{application-meaning}

This result checks bookkeeping, not target/source usefulness.

For observations, each labelled test can mean ``this source group
matches the chosen observation.'' Different source groups may have
different alphabets. The proof applies to that pattern. A
\href{../../SXPID3_ARBITRARY_ALPHABET_COUNT_PROPOSAL_2026_10_12.md}{22-theorem
arbitrary-alphabet/count proposal} has source review, not compiler
acceptance; its two counterexamples remain visible.

Neural recordings, brain imaging, sensor fusion and world-model outputs
need explicit inputs, targets, encoding, dependence and decision
objectives. Quantizing continuous embeddings changes the quantity

\section{Rust implementation and computational
cost}\label{rust-implementation-and-computational-cost}

Default API: stable::categorical::discrete\_sxpid3,
crates/pid-core/src/sxpid.rs; empirical categorical shared exclusions,
in nats. No API change or established
registry/count/inversion/arithmetic refinement.

Rust inputs are three categorical source matrices and a target with
aligned rows. Let \(N\) count rows, \(D\) count all coordinates, and
\(K\) count distinct complete joint rows. Groups can contain several
columns. The
\href{../../../RUST_IMPLEMENTATION_AND_COST.md}{source-derived cost
baseline} gives the general three-source route time
\(O(ND\log(\max(2,N))+DK^2)\), averaged storage \(O(ND)\) and pointwise
output storage \(O(K(18+D))\), including labels. These are bounds, not
timings. Here \(O\) bounds growth; log is natural; 1 GiB is \(2^{30}\)
bytes. The specialized API has a separate inversion path; no general
exact visit count is assigned to it. Empty/mismatched inputs and counts
above \(2^{53}\) are refused. Defaults guard estimated memory at 1 GiB
and coarse work at \(10^{10}\) units. Cancellation is cooperative, not a
hard memory/deadline promise. Logarithms remain rounded binary64. No
preprocessing, training, inference, resampling or online task benchmark
is reported; offline diagnosis is the intended first use.

Candidate compilation took 3.075696125 seconds; fresh replays took
66.562871750 and 66.881076458 seconds on the current Apple Silicon host.
These are proof-check timings, not estimator benchmarks or atomic
snapshots.
