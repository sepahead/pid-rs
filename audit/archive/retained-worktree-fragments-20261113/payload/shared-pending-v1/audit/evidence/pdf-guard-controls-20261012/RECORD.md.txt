## Contract and limits

records. Intermediate mode allows only five complete, constrained reference
convergence records. Same-line injections, mixed records, CRLF and missing
final newline are covered. CRLF means carriage-return/line-feed line endings.

Review caught an incorrect test oracle before execution: intermediate mode
must omit an allowed rerun line while reporting the following warning. The
corrected expected output preserves this behavior rather than changing it.

file:line errors are not exhaustively recognized by this helper. Native
success does not prove PDF correctness, portable runtime closure, accessibility,

are not a preregistered scientific test. No kernel, judge or numerical flags
changed. Formal-PDF-set, affected leaf, hosted and publication gates stay open.
