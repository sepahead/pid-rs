## Why the initial preflight stopped

The controller lists nine dependency packages. It requires each package and
cache route to be a directory. Initialization calls that check **before** its
internal start marker and either planned child: Lean version, then observer.

If earlier guards pass, the absent Cli route therefore causes preflight failure
before a Lean child starts. An earlier guard failure also cannot produce the
requested inventory. This is a source implication under the observed filesystem
state, **not an executed controller failure**. No invented native return code
or terminal child receipt is reported.

The wrapper requires the external ledger to be spent before preflight.
Executing the known-broken plan would consume the attempt without the requested
Lean output. Syntax success cannot repair the route; absence of the internal
start marker would not permit retry.

The other eight cache routes were observed by the reviewer, not independently
enumerated by ROOT here. Directory availability does not prove all objects
complete, matched to source, or selected by the future runtime.
