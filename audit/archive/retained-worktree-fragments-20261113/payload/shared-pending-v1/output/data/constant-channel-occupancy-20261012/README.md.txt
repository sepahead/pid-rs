# Constant-channel occupancy count packet

This directly runnable reference unit accompanies the
[occupancy reduction report](../../CONSTANT_CHANNEL_OCCUPANCY_SCREEN_2026_10_12.md).

Read [STATUS.md](STATUS.md) before reproducing anything. It states the exact
input/source pins, commands, native evidence and limits. [counts.json](counts.json)
is a portable projection; [count_pir.py](count_pir.py) is unchanged reference code.

The counter evaluates no entropy or PID. The report's bounds are hand-derived;
no population confidence, held-out gain or qualified PDF follows from this packet.
