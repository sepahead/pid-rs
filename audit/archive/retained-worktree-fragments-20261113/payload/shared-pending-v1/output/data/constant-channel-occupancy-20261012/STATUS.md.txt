## Reproduction instructions, not a new grant

Obtain Occupancy_Estimation.csv from the cited provider. Verify its size and
SHA-256 above; a different byte image is a different input and the fixed
counter refuses it. Use a canonical absolute path to a regular, non-symlink,
single-link input. Choose an existing canonical output directory and a NEW
output filename: the counter refuses an existing destination.

For stock Python, the command shapes are:

~~~text
python3.14 -I -S -B count_pir.py --input /absolute/path/Occupancy_Estimation.csv --output /absolute/path/new-counts-normal.json
python3.14 -I -S -B -O count_pir.py --input /absolute/path/Occupancy_Estimation.csv --output /absolute/path/new-counts-optimized.json
~~~

Replace both /absolute/path prefixes with your verified paths. These are
reader instructions, not executions or permission to bypass local controls.
The isolation/no-site/no-bytecode switches are the counter's unchanged
contract; -O is the separately recorded comparison mode, not a repair.
Input capture is checked before and after under a stable-host premise,
not an atomic snapshot or full loader attestation. No network or subprocess
is used by the counter.
