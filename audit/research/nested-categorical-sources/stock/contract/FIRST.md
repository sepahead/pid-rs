# First reading for the finite logical part of the nested-readings theorem

I wrote and checked an ordinary proof for the finite categorical MGW method before this formal task. The proof and observed exact cases are exposed. I have not seen either reviewer's independent critique of the new formal predicate. The proposed proof should treat each branch as a nonempty finite conjunction of indexed statements and each node as a nonempty finite disjunction of branches. Natural numbers index the source levels. A branch may repeat an index, and two branches may coincide. The logical statement should therefore not require a claim that an input is already in a canonical representation. For a canonical antichain of finite sources, form one conjunction per original branch and join the branches by disjunction. The index reduction at a conjunction is the greater of the two levels. The reduction at a disjunction is the smaller. A decreasing truth predicate is enough for each fixed outcome. The suffix condition has the opposite logical operations: at least one index in each branch must exceed or equal the threshold. Neither property follows by definition from the other.

Freeze five obligations: suffix membership for a branch and a node, evaluation for a branch and a node at every decreasing predicate, and a telescoping sum of arbitrary signed integer values through the node's level. The last assertion represents the arithmetic of differences only. The predicate has explicit models, including a threshold cut; an isolated fine true value without the required coarser matches violates evaluation on a concrete conjunction. The mixed branches {1,3} or {2} distinguish max and min, both directions of suffix incidence, and true and false cuts. Idempotency examples cover a repeated label and a repeated branch. The statement uses finite syntax trees, not decoded dataset bytes. Entropy, probability, full finite-poset inversion, all 108 products, real logarithms, conditional sampling claims, stable Rust refinement and literature priority each require separate evidence.

Compare relying on the published definitions alone, no formal step, CMI alone as a task comparator, enumerating 18 concrete nodes, a bit-mask truth table only, an abstract order with the incidence equivalence as a premise, decreasing real-valued weights instead of events, an explicit set-of-rows implementation, encoding the finite family as inhabited syntax then proving its min/max property, and a full measure-theoretic or Möbius library formalization. Only the finite syntax proof directly tests the missing logical implication without assuming the target result, choosing a numeric population or requiring a costly unrelated library. If the input model fails to represent a branch, or the theorem silently assumes a target identity or omits disjunction, the proof route must be reopened. Enumeration remains an adverse check, the empirical data model needs a separate mapping, and the full measure-theoretic proof remains a distinct route.
