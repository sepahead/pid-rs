# Threshold and event reading

25 November 2026. I have seen the earlier three-source event and order proof and the editor’s new question. I have seen no proposed definition, proof term or kernel task from this new step. This is an independent specification critique conditional on that shared theory.

Use an arbitrary nonempty finite expression. A leaf is a source i of rank l(i) in a linearly ordered type. Two constructors make an intersection of two subexpressions or a union of two subexpressions. For the event result quantify over every decreasing predicate P on ranks: if s ≤ t and P(t), then P(s). Define the expression value as P at a leaf, conjunction at intersection and disjunction at union. Define the expression level m as rank, maximum at an intersection and minimum at a union. Then the expression is true iff P(m). Applied to a point u and a decreasing family of events F, P(t) means u belongs to F_t; this gives equality of sets by membership. The claim permits arbitrary depth, one leaf, repeated leaves, equal ranks, constant predicates and noninjective ranks. The elementary proof is induction and the comparability of the two child levels. No probability or finiteness of a population is needed. A DNF version with a nonempty finite family of nonempty finite branches is sufficient for MGW.

Distinguish two predicates. For a threshold j, the suffix S_j consists of the singleton branches whose source ranks are ≥ j. In disjunctive normal form, S_j lies below a node exactly when EVERY branch has AT LEAST ONE source of rank ≥ j. This is equivalent to j ≤ min_B max_{i∈B} l(i). Recursively, the hitting predicate is j ≤ l(i) at a leaf, disjunction at an intersection and conjunction at a union. In the ordinary independent-variable semantics an equivalent test is whether the original monotone formula is false when all ranks < j are set true and all ranks ≥ j false. This is not the assertion that every used source is in the suffix, or that some used source is. A programmer can make the formal result tautological by defining below as j ≤ m. Instead define a syntactic hit/selection relation independently of m, linking it to the actual branch order above. A generic tree hitting predicate needs a separate DNF-distribution or implication proof if a claim about the existing finite antichain carrier is intended. To call the suffix an actual antichain node, use a finite index type and a threshold with at least one eligible source; a threshold above every rank gives the meaningful false test but an invalid empty node.

Adverse controls: with ranks 1 and 3 and j=2, the intersection hits but the union fails. With P(s) iff s≤2, intersection fails but union succeeds. These distinguish both swapped conjunction/disjunction and swapped min/max. With (1 OR 3) AND 2, j=2, one child supplies a hit although its sibling does not; with (1 AND 3) OR 2 likewise no single common high-rank source occurs in every expanded branch. A predicate increasing from false at 1 to true at 3 violates event reduction on intersection; this tests the monotonicity premise. Equal ranks work in both constructors. One-leaf constant-true and constant-false give inhabitation but cannot diagnose swapped operations. Reverse order and empty branch/family must be tested or excluded; empty intersection/union cannot be handled uniformly without suitable endpoint events. Use a small nonconstant, independently evaluated input of each constructor and an actually failing changed statement, plus no added axiom or wrapper defining the conclusion as the premise.

Limits: stock checking covers only the exact typed inductive formulae, ordering and stated assumptions. Identify any route from the indexed public 18-node carrier to this type; prove that route if claiming coverage. It does not prove MGW event correspondence, entropy identities, exact product algorithms, finite precision, directed margin, empirical completeness or deployed sensor reconstruction. Audit axioms/imports and complete stock streams at the named declarations. The known mathematical argument is already exposed; a prospectively frozen formal predicate can give separately scoped kernel evidence.
