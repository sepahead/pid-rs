# The 22 weighted-row declarations and their source meanings

Use this table with the [derivation and examples](README.md). The order and spelling match the original recorded Lean 4.34.1 theorem records. The theorem names all have prefix `PidFin3AlphabetCounts.`. Each raw target has prefix `PidFin3CountRaw.`. Each typed consumer has prefix `PidFin3CountConsumers.`. The source type, exact printed elaboration and receiving obligation are available for every row. [Raw target definitions](https://github.com/sepahead/pid-rs/blob/add8134a0c3df6142dcf74b02d9cb14c797bd8ce/audit/research/three-source-alphabet-counts/lean/CountRaw.lean) · [Recorded declaration stream](https://github.com/sepahead/pid-rs/blob/add8134a0c3df6142dcf74b02d9cb14c797bd8ce/audit/research/three-source-alphabet-counts/declarations.txt) · [Machine-readable ledger](ledger.tsv)

Three coordinates form the type `Fin 3`. The index type is `J`. Its finite set `K` carries weights in the natural numbers including zero. Source types may differ by coordinate. The target has its own type. Finite sums require only the supplied finite indices. Ambient labels may be infinite. In the decision column, `J` means decidable equality of indices, `S` means decidable equality in each source type, and `T` means decidable equality of target labels. `E` and `F` mean decidability of the corresponding predicates. A dash means the raw target needs none of these instances. Individual rows list all additional logical premises. Unless specified, the key can be any index and the family can be any finite family. Validity of a scientific node is a separate restriction. Each source locator refers to arXiv revision 5. These are count-level translations of the referenced equations. The paper does not state these 22 Lean propositions. [Primary text](https://arxiv.org/pdf/2002.03356v5)
