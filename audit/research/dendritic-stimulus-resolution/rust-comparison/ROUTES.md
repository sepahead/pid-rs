# Design choices and scientific reading

Select the protected client calling both public categorical routines. It addresses the concrete transfer from an exact finite numerical reference to the software an applied reader can call.

| Route | Needed premise | Failure or reason for this selection |
|---|---|---|
| Preserve only the existing reference | A citation of software suffices for the intended claim | It cannot say what the Rust implementation actually returned. |
| Direct counts and conditional entropy | Only total additional predictive information matters | A necessary baseline. It has no 18 individually labeled atoms. |
| Cross-validated prediction | The goal is class or logarithmic loss under the declared split | The existing study already supplies these outcomes. They test a different question. |
| Reimplement both formulas in Python | A second formula checks the first at the same finite input | Retain the existing two-code reference. It cannot measure the public binary64 behavior. |
| Call a pre-installed Python wheel | Its complete Rust build and bindings are identified | The installed extension and its exact source are not bound here. A fresh binding comparison could supply this later. |
| Link a cached rlib | Its dependency closure, features, compiler flags and source revision are established | This provenance was not sufficient in the local cache. |
| Compile the two public native APIs from the original lock and Git tree | Required crates are present in the offline cache and serial resource limit is met | Selected. If the compile or input preflight fails, preserve the failure. |
| Use the full pointwise categorical result | Storing local information is part of the question | Averages answer every current predicate with less allocation. Per-row refinements can take a separate field. |
| Compare vectors by position | The two original APIs and external reference serialize identical key orders | The source does not guarantee that. Check the actual source masks and register an order-reversal positive control. |
| Compare one largest atom or signed terms only | It suffices to detect large differences | This omits the subcomponents and makes opposite errors cancel. Check all 216 positions. |
| Refit an observational model or rerun NEURON | The estimand is a new sample distribution or calibration | One stored deterministic design grid has no such information. Separate simulations or experimental replications would be new inputs. |
| Prove universal real-to-binary64 refinement | Complete specifications for every library numerical path and arithmetic primitive | A finite integration test cannot establish this theorem. The exact reference and scoped native outputs stay available. |

The reviewing questions cover the following separate failure opportunities. Source identity, revision, license, row orientation, column orientation, published figure, contradictory plotting labels, nominal versus actual synapses, with-replacement selection, soma spike measurement, absent loops, overwritten data, frequency exclusions, ordered rows, missing rows, extra rows, integer counts, spike threshold, output leakage, repeated condition weights, strict input inequality, flag timing, equality case, edge bins, no fitting, empirical support, active marginal states, monotonic mask encoding, group conjunction, mask union, lower-set convention, antichain validity, duplicate label, atom versus cumulative, pointwise versus average, informative sign, misinformative sign, signed subtraction, method provenance, source grouping, target role, common sampling input, target prior, units, rational normalization, count multiplicity, relative accuracy at zero, absolute accuracy, interval orientation, bit order, NaN, infinity, token type, iteration order, native metadata, Cargo features, compiled lock, provenance of an existing binary, build resources, replay resources, memory sampling, time limits, grader exposure, reference dependence, host dependence, external deployment and independent human review.

One independent pre-adapter reader correctly recovered the source axes and identified the need for a neighboring-float allowance and atom-versus-cumulative controls. That note proposed a different 216-count expression with two resolutions. The present study has three widths, 18 nodes and four atom channels. The first mathematical reader correctly distinguished designed metadata from an independent sensor but initially repeated the reversed plotting comments. The checked correction uses two primary figures and the original generator; this prior failure remains recorded. The shared dependencies include the same original law, target choice, functional definitions, reference values, operating system and physical computer. The scientific content and source comparisons remain model-based. Counting these lenses is a coverage inventory.
