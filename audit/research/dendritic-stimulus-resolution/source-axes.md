# How the two stimulus axes were identified

The array has 31 rows and 21 columns. Two comments in `PhenomModels.m` label the 21-value horizontal array as basal and the 31-value vertical array as tuft. The first reader repeated those labels. The sealed source note and the comments remain available. The original simulator sets 30 basal steps and 20 tuft steps, with ten requested inputs per step. It loops over basal settings first and tuft settings second. Its active print statement lists the selected settings and the recorded somatic spike count. It starts a new line after the tuft loop. The two numeric file-write statements are commented out in this distributed version. The analysis uses the archived output file. The control figure in Shai et al. has a basal axis from 0 to 300 and a tuft axis from 0 to 200. Independent confirmation comes from the full 31 by 21 grid and the source descriptions and Table 5 in Kay et al. The public script distributes inputs by random indices; the reported counts are nominal settings. The analysis uses file row for basal and file column for tuft. Confusing the two would change the physiological name of the source and reverse the meaning of the comparison bit except at ties.

The compact numeric table and data-generating code agree under this orientation. The first note supports the mathematical distinction between a deterministic third variable and one that has residual variation after grouping. Its original names for the input axes have been superseded. This observation concerns the retrieved plotting script. It does not allege an error in either published paper.
