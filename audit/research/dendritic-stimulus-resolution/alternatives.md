# Alternatives fixed before calculating a benchmark outcome

| Route | Assumption and failure condition | Disposition and evidence that can change it |
|---|---|---|
| Do nothing | Input settings might already have full precision. | Keep the full-precision negative control; the exact input-only bit is then determined. |
| Count class decisions directly | The loss is one for any incorrect class and zero otherwise. | Primary engineering comparator. A different loss or prior needs a different decision. |
| Oracle log score and conditional information | Full class probabilities refer to this grid with its assigned weights. | Primary probability comparator. It gives the total gain and no five-position breakdown. |
| Evaluate a fitted predictor with held-out input levels | Add-one smoothing and the stipulated empty-cell rule are used in every fold. | Include both axis-wise blockings, including losses. A new simulator or neuron needs new data. |
| Measure stimulus-response curves directly | Output classes and input orientation must agree with the primary simulator. | Include an input-space figure and the published two-input summaries. They can show threshold effects without any PID. |
| Five signed MGW atoms | Use supported categorical outcomes and MGW's nonnegative informative and misinformative parts. | Include all five and the sum of negative magnitudes, even if zero. An alternative redundancy functional changes these values. |
| Williams–Beer minimum redundancy | Use the minimum specific information per observed target class on this finite grid. | Exact comparator on the same data. Its atoms are nonnegative by construction; signed MGW cancellation does not compare predictive quality. |
| BROJA | Its usual two-source unique-information optimisation does not give this named three-source 18-node result. | Cite Kay and colleagues' published two-source comparison. Require a specified multivariate extension before a new numerical comparison. |
| Permutation importance | Shuffling a derived flag across exact settings creates physically impossible inputs. | Do not use unconditional shuffling. Exact empirical conditional distribution and refitted ablation cover identifiable comparisons. |
| Logistic/ordinal regression or original composite sigmoid | A parameterized response model can extrapolate where lookup data are sparse. The published mechanism predicts frequency and the present response is grouped spike counts. | Retain the published model as a distinct baseline question. A common outcome, fitting split and explicit model would permit a predictive comparison. |
| Calcium manipulation or causal mediation | Intervention assignment and multiple trials would be needed to identify uncertainty and mediation. | Treat spikes_noCa.dat, frequency files and quarter-conductance files separately; their filenames do not authorize pooling or interpreting the present flag as a pathway. |
| Test a field sensor or new neuron | Recorded settings, preprocessing and evaluation data would need the intended target, actions, loss and costs. | Keep the human, retinal and robot cases in the source survey. Physically recorded wrist and office results have their own scopes. No simulation success transfers automatically. |
