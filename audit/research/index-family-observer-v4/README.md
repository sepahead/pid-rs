# Bounded observation of 170 artificial theorem declarations

Sepehr Mahmoudian · 21 November 2026

Can stock Lean return the complete stored type and proof of every theorem in a fixed artificial example under the existing memory and time limits? The first run compiled its four mathematical modules and completed four fresh kernel checks. It then exceeded its 4 GiB memory limit in the program that was to print all 170 stored declarations. It printed no term record. This separate procedure keeps the mathematical input and uses a fresh observer process for each of 87 prescribed groups. It draws no conclusion about the cause of the earlier memory peak or the success of a future run. A *finite index* is a natural number below a stated bound. The index here runs from 0 to 82. A *guard* is a condition required by a theorem. A *term* is a stored expression for a type or proof. An *axiom* is a stated assumption. A *direct dependency* is a named constant that occurs in the stored expression. A *fresh check* asks the stock checker to replay eligible stored declarations in a new kernel environment. All inputs are invented counts, with no sampling or information units. The two consumers state the same proposition for every index and every natural argument. The two calculations agree if readiness is true and the index is positive. The fixed already public input supplies a proof by named cases and a separate proof with all cases in one slot. ## Rust implementation and computational cost

This is a proof-checking experiment. It has no Rust estimator, statistical sample, fitted parameter or real-time operating claim. The registered host is one logical CPU on standard x86-64 Linux with stock Lean 4.34.1. The inherited bounds are 4 GiB direct or sampled process-group resident memory, 900 seconds per command and 2,700 seconds across the campaign. The Python postprocessor has the same limits. All inputs, objects, raw streams, joined output, source snapshots and metadata in the evidence directory share the 1 GiB budget. The compressed and expanded archive each has a 1 GiB ceiling and the archive allows at most 550 members. The downloaded and extracted stock supplier has a separate location. The outer workflow stops after 55 minutes. Repeated compiler startup and a single large representation can each limit this procedure. The stock program records direct peak memory at process exit. It also samples the group while the process runs. A quick process can finish before the first sample. The raw record retains the sample count. The source packet reports no new native time or scientific result. [Charged native schedule](run.py) · [Resource measurement](../three-source-original-reachable-v3/native_resources.py)
