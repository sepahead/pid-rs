## Rust implementation and computational cost

Use Python 3.11 or later. Save the original ZIP as **robot.zip**. From the study directory run the following commands. A local check reads the named archive and the original program outputs. The two controls at the end of the first command change individual donor bytes and verify the original procedures refuse them.

~~~
python3 -I -S -B replay.py robot.zip --self-test
python3 -I -S -B -O replay.py robot.zip --self-test
python3 -I -S -B figures/check.py
python3 -I -S -B rust/replay.py --archive robot.zip --recorded
~~~
