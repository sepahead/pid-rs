\begin{abstract}
This source-read audit compares the recorded source states of Prisoma,
Galadriel, Haldir, Crebain, and pid-rs.  It separates implemented behavior,
proposed behavior, stale documentation, unsupported assumptions, and missing
evidence.  The reviewed consumer sources contain no qualification evidence for
the pid-rs source base reviewed here.  The strongest workable route is an offline categorical or
independently frozen quantized analysis with explicit target, row, transform,
support, selection, and uncertainty contracts.  Continuous KSG and
shared-exclusions PID remain restricted research routes.  PID evidence may never
grant or widen mission or plant authority.  Exact XOR, coherent-majority, and
target-rotation constructions show why pairwise agreement and changing-target
atom reports cannot carry stronger interpretations.
\end{abstract}

\section{Review method}

The audit used a claim-to-code trace rather than a keyword count:
\begin{enumerate}
\item Read each available repository instruction file and recheck source interpretations against it.
\item Record branch, commit, dirty state, dependency pins, and submodule pins.
\item Trace data from producer or adapter through preprocessing and estimator selection to terminal status and any authority boundary.
\item Prefer executable source and manifests over summaries; mark a document stale when it contradicts current code.
\item Challenge operational rules with exact negative constructions.  Direct enumeration of four equiprobable binary states verifies the XOR and target-rotation identities.  The coherent-majority result uses the closed-form Gaussian MI formula.
\item Search manifests and Rust sources before reporting that no direct dependency was found.
\item Do not treat component tests, declared assumptions, or producer publication as end-to-end scientific evidence.
\end{enumerate}

Apart from the current-head Crebain source/component validation above, the
audit did not run consumer release qualification, a live Neuro-Cybernetic
Protocol (NCP)/Galadriel deployment, or a statistical calibration study.
Companion PDF build and render checks are a separate presentation-integrity
evidence layer; they do not fill those scientific or operational gaps.

\subsection{Terminology}

The phrase ``colored PID'' does not name a PID measure.  Dependency coloring
qualifies a finite-sample concentration theorem for categorical SxPID under a
specified row-dependence contract.  It constrains dependence among sample rows.
It is not a new PID functional,
estimator, or term attributed to Makkeh, Gutknecht, or Wibral.  Consumer
documentation should use \emph{dependency-colored concentration for categorical
SxPID}.

The executive rows are not single-lens conclusions.  Each determination is
justified by the seven-lens assessment below.  A route fails qualification if
any required lens remains unsupported.

\section{Minimal mathematical primer}

For discrete random variables, mutual information is
\begin{equation}
 I(X;T)=\sum_{x,t}p(x,t)\log\frac{p(x,t)}{p(x)p(t)}.
\end{equation}
It is zero exactly when $X$ and $T$ are independent.  It measures statistical
dependence, not causality, truth, intent, or fault.

A two-source PID resolves the total information as
\begin{equation}\label{eq:pididentity}
 I((S_1,S_2);T)=\operatorname{Red}+\operatorname{Unq}_1+
 \operatorname{Unq}_2+\operatorname{Syn}.
\end{equation}
The target $T$ is part of the definition.  Changing $T$ changes the
decomposition.  Shared-exclusions PID also separates informative and
misinformative pointwise components; signed net atoms can be negative.
The $\Imin$ measure of Williams and Beer uses a different redundancy definition
and must not be reported as shared-exclusions PID\@.

Categorical routes operate on finite empirical count tables.  KSG and continuous
ISX use local-neighbourhood geometry and require stronger support, sampling,
dimension, and tie assumptions.  Correct formulas and clean component tests do
not establish those application premises.

\subsection{No-transplant rule}

Let claim $C_M$ be proved or validated for a measure or estimator $M$.  It may
be used for another measure or estimator $N$ only if an explicit mapping theorem
states the distribution class, target and source semantics, lattice coordinates,
normalization and units, numerical representation, and the property preserved by
the map.  Shared atom names, a common reconstruction identity, similar benchmark
values, or use of the same MI terms are not such a theorem.
This review found no mapping theorem in the checked source that licenses any
transfer below.

Consequently:
\begin{itemize}
\item $\Imin$ results do not validate SxPID atoms;
\item categorical SxPID theorems do not validate continuous ISX estimators or claims about an unquantized law;
\item KSG MI checks do not validate continuous PID atom bias, variance, or coverage;
\item two-source results do not validate three-source or mixed-dimensional lattices; and
\item a pairwise-MI consensus rule does not become a PID decision rule because PID atoms appear in the same report.
\end{itemize}

When no mapping theorem exists, the adapter must report separate estimands and
separate evidence.

\section{Minimum cross-consumer contract}

An adapter must retain the fields below.  A label without evidence is not a
certificate.

\subsection{Identity}

\begin{itemize}
\item Consumer repository, commit, dirty state, build features, and executable identity.
\item Exact pid-rs revision, crate version, API revision, method-catalog entry, and catalog digest.
\item Reported units: pid-rs information quantities use natural logarithms and nats.
\item Exact estimator family.  $\Imin$, categorical $\Sx$, quantized $\Sx$, and continuous $\Sx$ are different routes.  One is not a silent fallback for another.
\end{itemize}

\subsection{Scientific roles}

\begin{itemize}
\item One target and one ordered, labelled source tuple.
\item Physical meaning, units, common frame, and horizon for every variable.
\item Row unit: frame, episode, track window, trial, subject, or another declared unit.
\item Population or finite-population estimand.  A window statistic is not automatically a fleet or trajectory estimand.
\end{itemize}

\subsection{Sampling and support}

\begin{itemize}
\item IID, stationary, exchangeable-block, dependency-color, or unsupported row status.
\item For a dependency coloring, a deterministic color map and a justification of \emph{mutual} independence of complete rows within a color.  Pairwise uncorrelatedness is not enough.
\item Drift and selection declarations.  Concentration about an average row law does not identify one fixed target law without a drift bound.
\item A categorical alphabet identity or a continuous/mixed support declaration.  Unique observed rows cannot prove a regular full-dimensional population law.
\item A population support floor only when a theorem requires it.  An observed minimum cell mass cannot replace an unknown population floor.
\end{itemize}

\subsection{Preprocessing}

\begin{itemize}
\item Training and evaluation row identities and disjointness at the episode or subject level.
\item Frozen transform parameters or bytes, source order, training digest, and application digest.
\item Target-adaptive selection and fitting outside the evaluation rows.
\item Quantizer edges as part of the estimand.  Same-row bins define a descriptive, data-adaptive quantity.
\item Added noise only under a declared observation model or labelled sensitivity study.  Noise changes the estimated law; it is not a generic tie repair.
\end{itemize}

\subsection{Estimator, status, and replay}

\begin{itemize}
\item Metric, neighbour count, gauge, seeds, resources, and signed negative handling.
\item Distinct \texttt{produced}, \texttt{warning}, \texttt{abstained}, and \texttt{failed} outcomes.  Invalid output must not become zero.
\item Signed informative, misinformative, and net atoms where available.  A negative net atom is not a causal, fault, intent, or responsibility finding.
\item Exact interval status: numerical enclosure, calibrated confidence interval, raw resampling percentile, or sensitivity envelope.
\item A predeclared testing family and valid p-values before BH or BY\@.
\item Input, transform, configuration, output, run-log, and software-identity digests, including terminal failures.
\item An explicit advisory-only/no-authority marker.
\end{itemize}

\section{Prisoma}

\subsection{Implemented route}

Prisoma consumes the pid-rs submodule at
\Commit{796c11e70f009634b853dc4ada6f565563d82f51}.  The harness records this
revision in \path{crates/pid-sim/src/offline_harness.rs}, lines 3937--3938.
This pin predates the pid-rs source reviewed here.  Current-main compatibility is
not established.

The harness implements continuous KSG/ISX screens under a caller support
assertion, discrete and discrete-PLS $\Imin$ screens, fitted equal-width
quantization, and typed abstention.  Its own documentation correctly says that
\texttt{assume\_regular\_full\_dimensional} is an assertion, not proof
(lines 4276--4286).

\subsection{Confirmed SAFE schema defect}

The Python SAFE adapter states that it mirrors the Rust dataset exactly.  It does
not.  The Rust \texttt{OfflineVldaDataset} has a top-level support map.  A missing
axis fails closed as \path{support_contract_unspecified}
(\path{crates/pid-sim/src/offline_harness.rs}, lines 369--378, 3964, and
3998).  The Python \texttt{VldaDataset} has only samples and four optional text
fields.  Its serializer emits no support map
(\path{experiments/safe_adapter/contract.py}, lines 147--211).  The converter
and verifier also omit it.

Thus a JSON object can pass the Python verifier and make every continuous Rust
tuple abstain.  This is a reproducible cross-language schema incompatibility.
The repair is concrete:

\begin{enumerate}
\item Add closed support declarations for \texttt{v}, \texttt{l}, \texttt{d}, and \texttt{a}.
\item Reject absent, unknown, or contradictory declarations in Python.
\item Preserve capture integrity and publication receipts when required.
\item Retain an old-schema negative fixture that must end in \path{support_contract_unspecified}.
\item Remove the word ``exactly'' until a cross-language golden test proves it.
\end{enumerate}

\subsection{Same-row fitting is descriptive}

Discrete-PLS fits each source toward the target on the rows supplied to the
screen and transforms the same rows.  Equal-width quantization likewise fits and
transforms the same matrix.  The source correctly labels these paths descriptive
(\path{crates/pid-sim/src/offline_harness.rs}, lines 1291--1328 and
4302--4314).  Leave-one-out component selection does not make the final same-row
projection held out.

The following construction shows why a split is essential.  Let
$X\in\mathbb{R}^{n\times p}$ be a continuous noise matrix independent of binary
target $T$, with $p\geq n$.  With probability one, $X$ has row rank $n$.
Consequently, a target-adaptive linear fit can choose $w$ such that $Xw=T$ on
the evaluation rows.  Let $\widehat P_n$ be the discrete empirical law assigning
mass $1/n$ to each fitted pair $(Z_i,T_i)$, where $Z=Xw$.  Then
\[
  I_{\widehat P_n}(Z;T)=H_{\widehat P_n}(T)
  \quad\text{on the fitted rows, while}\quad
  I(X;T)=0
\]
under the population law.  This finite-table identity is not a claim that KSG
is valid on the resulting tied, singular sample.  It does not assert that every
PLS call interpolates.  It proves that same-row target-adaptive fitting alone
cannot support inference.

\subsection{Holdout and workable regime}

\path{protocols/holdout_registry_v1.json} records
\texttt{holdout\_count: 0}.  The H3 power path also reports missing local
PID/CI features, leakage tests, censoring rules, and mandatory baselines
(\path{crates/pid-sim/src/power.rs}, line 1383).

A realistic Prisoma route requires a fixed target, low-cardinality categorical
variables or a training-fitted frozen quantizer, disjoint evaluation episodes, a
valid row-dependence contract, preregistered endpoints, retained atom signs and
abstentions, and one registered confirmatory holdout.  High-dimensional learned
embeddings, same-row PLS, adaptive bins, and unrestricted continuous PID are
outside that regime.

\section{Galadriel}

\subsection{Implemented rule}

Galadriel pins pid-core to this revision:
\begin{center}
\Commit{1cd2424f7967e1752dcc8e53859e8fdad3566f51}
\end{center}
The dependency enables \texttt{experimental-pipelines}.  The pin does not match

The PID path is optional and off by default.  Signed-correlation analysis remains
the default.  Galadriel's architecture rules state that \texttt{Nominal} cannot

\texttt{Nominal} (\path{AGENTS.md}, lines 117--146).  These are correct permanent

The decision rule in \path{crates/galadriel-pid/src/engine.rs}, lines

floor and strongest pair, finds the largest MI clique, requires one unique
strict majority, and attributes an excluded channel only when all its clique
edges are assessed and low.

The $\Sx$ redundancy and synergy values are computed separately and never drive
the verdict.  The accurate name is \emph{pairwise-MI consensus with report-only
PID atoms}; it is not a PID verdict.

The code asserts a regular full-dimensional support model and adds deterministic
Gaussian pseudo-noise through pid-rs \texttt{Jitter}.  Current pid-rs states that
this primitive changes the law, drops application provenance, and is not generic
tie repair.  A recorded scale and seed do not prove the population noise model,
finite MI, IID rows, or calibration.

\subsection{Counterexample: pure synergy}

Let $X,Y\sim\operatorname{Bernoulli}(1/2)$ be independent and set
$T=X\oplus Y$.  Then
\begin{equation}\label{eq:xor}
 I(X;Y)=I(X;T)=I(Y;T)=0,
 \qquad I((X,Y);T)=\log 2.
\end{equation}
Conditional on either input, $T$ remains fair.  Given both inputs, $T$ is
deterministic.  The pairwise graph has no positive edge despite exact
three-variable dependence.  A positive MI floor therefore yields insufficient
evidence, and report-only atoms cannot change the verdict.

Equation~\eqref{eq:xor} is a structural counterexample to the decision
statistic.  Binary data are not offered to the continuous KSG estimator.  The
result shows that pairwise consensus is not a general synergy detector.

\subsection{Counterexample: coherent-majority inversion}

Let $A,U,E_1,E_2,E_3$ be independent standard Gaussian variables and define
\begin{equation}\label{eq:majority}
 M_j=A+\sigma E_j\quad (j=1,2,3),
 \qquad H=U,
 \qquad \sigma>0.
\end{equation}
Every pair $(M_i,M_j)$ is regular jointly Gaussian with
$\rho=1/(1+\sigma^2)$.  Therefore
\begin{equation}
 I(M_i;M_j)=-\frac12\log(1-\rho^2)>0,
 \qquad I(H;M_j)=0.
\end{equation}
For a threshold between these values, the unique strict-majority clique is
$\{M_1,M_2,M_3\}$.  The rule attributes $H$ as decoupled.  If the three coherent
channels share one fault or spoof while $H$ is correct, attribution is reversed.
The rule identifies agreement, not truth.  Geometry and delete-block checks do
not provide a trusted reference label.

\subsection{Counterexample: targets rotate across atom rows}

The atom helper sorts all channels other than row $i$, uses the first as source
two, and uses the mean of the remainder as target.  For three modality keys
$X<Y<Z$, Table~\ref{tab:targetrotation} follows directly from the code.

Input list permutation is stable; target rotation is a different semantic
question.  Let $X,Y$ be independent fair bits and encode $Z=(X,Y)$ as one
four-state variable.  Then
\begin{equation}\label{eq:targetrotation}
 I((X,Y);Z)=2\log 2,
 \qquad I((Z,X);Y)=\log 2.
\end{equation}
Since PID atoms reconstruct the applicable total mutual information, atom
vectors cannot remain invariant when the right-hand side changes.  Cross-row
values are different decompositions and must not be treated as coordinates of
one fixed PID\@.

\subsection{Workable Galadriel regime}

The current engine can serve as an advisory dependence screen only when scalar
common-frame projections and a window are fixed, population support is
defensible, row dependence and drift are declared, data pass the estimator
gates, thresholds are calibrated for the exact repeated-window policy, and
coherent-majority cases are included.  It remains non-causal and
non-authorizing.  It is not a pure-synergy detector, trusted-majority oracle,
calibrated attack posterior, or general fault locator.

\subsection{Permanent authority non-expansion}

The Haldir authority model says advisory evidence cannot grant or widen authority
and a failed or missing conjunct has no fallback.  Let $A_0(s,a)$ be Haldir's
authority predicate before PID evidence, and let
$A_{\mathrm{PID}}(s,a,e)$ read PID evidence $e$.  The permanent invariant is
\begin{equation}\label{eq:noauthority}
 \forall s,a,e:\qquad
 A_{\mathrm{PID}}(s,a,e)\Longrightarrow A_0(s,a).
\end{equation}
The post-PID authorized action set must be a subset of the original set.  A
predeclared restriction $A_0\wedge R(e)$ is structurally allowed.  Any
$A_0\vee G(e)$, override of a failed conjunct, or conversion from an atom to a
plant command is forbidden.

Equation~\eqref{eq:noauthority} remains in force even after formal verification
or statistical calibration.  Correctness of a statistic does not confer
authority.  Unavailable PID remains unavailable; it does not become zero,
nominal, or permission.

\subsection{Workable Haldir regime}

PID may enter Haldir only as replayable advisory evidence or as a predeclared
restriction that cannot create an allow.  Missing, failed, abstained, and
numerically unresolved results must remain distinct states.  Runtime command
selection, effector routing, and safe-action selection remain outside pid-rs.

\section{Qualification sequence}

Do not collapse heterogeneous evidence into one ``confidence'' score.  Complete
and report these layers separately:

\begin{enumerate}
\item Cross-language schema conformance with golden and rejection messages.
\item Semantic conformance of target, source, event, lattice, and atom mappings against an exact small categorical oracle.
\item Executable refinement or bounded exhaustive checking of histogram, event, lattice, and atom correspondence.
\item Directed-rounding or ball-arithmetic numerical certification for categorical log terms and signs near zero.
\item Validation of the exact row process, support regime, transform split, drift, and uncertainty procedure.
\item Selection and sequential validation for the full predeclared family and repeated-window policy.
\item Independent hidden challenge after commits and thresholds are frozen, followed by publication of every case.
\item Exact consumer replay with run logs on pinned commits.
\item Machine-checked authority non-expansion and mutations that try to bypass every failed authority conjunct.
\end{enumerate}

The categorical offline path can in principle traverse all nine layers.
Continuous two-source PID first needs estimator-specific consistency and
calibration evidence in the consumer regime.  Full mixed-dimensional continuous
PID and authority use remain outside the release path.

\section{Final decision}

pid-rs addresses part of the ecosystem need.  It supplies a strong categorical
implementation, restricted continuous research estimators, typed failures,
provenance, resource controls, and several validation layers.  It does not
validate a consumer's target, rows, support, preprocessing, selection, repeated
alerts, or authority policy.

The immediate priorities are:
\begin{enumerate}
\item repair the Prisoma SAFE schema and add a held-out frozen-transform path;
\item name Galadriel's pairwise rule accurately and retain the XOR, target-rotation, and coherent-majority counterexamples;
\item correct stale Haldir API claims and encode permanent non-expansion;
\item implement Crebain receiver/window/scientific-contract receipts before a PID claim; and
\item qualify pinned consumer routes, not pid-rs in isolation.
\end{enumerate}

Until then, all four routes remain advisory, descriptive, experimental, or
blocked as stated.  No PID result may authorize an action.
