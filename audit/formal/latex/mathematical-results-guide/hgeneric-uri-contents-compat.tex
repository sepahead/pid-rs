% This Work adapts the URI-link part of hyperref-generic.dtx in
% latex3/pdfresources commit 6fbdf1ae266c5d59704374045a7abe90e59be4a3,
% "Add Contents entry to URI and GoTo links for better UA support"
% (2024-03-01), licensed under LPPL 1.3c or later. Commit
% 57caeb67fa785a92a05083f4eee1863d504f7a63 subsequently identifies the native
% hgeneric-testphase.def implementation as v0.96f dated 2024-03-01. See
% LICENSE-LPPL-1.3c.
%
% Ubuntu's reviewed hgeneric-testphase.def v0.96d dated 2023-12-09 predates
% the upstream change and leaves tagpdf's literal (url) placeholder in every
% URI Link annotation's /Contents. This compatibility layer writes the actual
% URI target as the same UTF-16BE PDF text string used by the native update.
% It does not change URI actions, GoTo links, structure parents, or the claim
% boundary: the guide is tagged, but this file does not assert PDF/UA.
%
% This is deliberately bounded to the 2024 target-valued /Contents policy and
% this guide's existing reproducibility contract. Upstream commit
% 0057659274b5f525948a81bdf93f769e5b36a6fb (2026-02-17, issue 111) later made
% link /Contents a no-op by default and enabled target text only for PDF/UA-1:
% repeated target announcements can be tedious for screen-reader users. That
% later policy needs separate assistive-technology review; target-valued
% /Contents is not claimed to be universally optimal or to prove PDF/UA. That
% change retained the 2026-01-23 v0.96y declaration, so declared dates cannot
% distinguish pre-change from post-change v0.96y bytes; the complete v0.96y
% family is conservatively outside this compatibility layer's reviewed range.
%
% The reviewed 2024 native path wins. A native state on an unexpectedly older
% file, a native-absent file dated 2024-03-01 or later, or any file declared
% 2026-01-23 or later fails closed. The fallback accepts only the exact declared
% date/version token family 2023-12-09 v0.96d, whose hosted source is separately bound
% by SHA-256. Required APIs are feature-tested and the exact v0.96d URI command
% is patched at the upstream insertion point inside its existing local group.
% That leaves the shared annotation dictionary unchanged after each link.
\makeatletter
\ExplSyntaxOn
% A reviewed native hgeneric must not allocate fallback state or change link
% writers. Probe it without allocating a message, sentinel, variable, register,
% or helper control sequence, then stop reading this Work before fallback state
% is created. Reading an extra input can change pdfTeX's automatic trailer /ID;
% the self-test therefore requires exact equality outside the sole typed,
% duplicated trailer-ID payload and separately checks action semantics. The
% ambiguous v0.96y family deliberately falls through to the fatal boundary.

            { }
            {
              \IfFileAtLeastTF { hgeneric-testphase.def } { 2024-03-01 }
                { \ExplSyntaxOff \makeatother \endinput }
                { }
            }
        \fi
      }
  }
