# Exact sources and local verification

This package contains the [frozen 47-input manifest](gradient-proof-package-v1.json), its exact
source files, and the separately selected candidate and cosmetic/wrong-target controls. The
[source inventory](PUBLIC_SOURCE_INVENTORY.json) records their bytes. Copying these files makes
the proof and checker inspectable; it does not create a new execution result.

The local replay on 14 September 2026 used Lean 4.33.0 and Mathlib commit
`db584cd6d46c92f209a44c0f1c829460d327499d`. Each positive run freshly compiled the 36-module
project graph, then invoked the separate checker with `--fresh GradientCandidateRoot`. The
selected and one-comment cosmetic sources each ran with normal and optimized Python. The last
control replaced the final theorem by `True`; both raw and alias target checks rejected it,
and the first ten semantic records remained unchanged. These runs verify one eleven-family
result; repeated variants do not multiply the number of theorems or establish independent kernels.

The adapter's frozen manifest excludes the candidate by design. It binds the judge and statement
closure first; a later candidate admission binds the selected proof. The runtime also requires
the declared repository Lean project, pinned helper scripts, installed dependencies, native tool
bytes, original UTC and monotonic endpoints, fresh PRE/POST dependency observations, and reviewed
control receipts. The package does not ship those machine-specific admissions. Existing expired
registrations must never be reused as permission for a new replay.

The [local acceptance projection](LOCAL_FORMAL_ACCEPTANCE.json) records the exact result hashes,
semantic names, universe counts and permitted axioms. Its source-to-proposition reading is a root
review informed by same-system independent-first critiques. Institutional independence, binary
authenticity, hostile-host safety, and paper correspondence do not follow from a kernel pass.
The [theorem map](THEOREM_MAP.md) records those separate edges.
