# Reading two existing Mathlib logarithm bounds

The reader observes two existing real inequalities in Mathlib. For a real number $0\le x<1$ and a natural number $n$, define the finite sum $A_n(x)=\sum_{i=0}^{n-1}x^{2i+1}/(2i+1)$. Use zero when $n=0$. The natural logarithm is denoted by $\log$. Mathlib proves that $A_n(x)$ is a lower bound for $\tfrac12\log((1+x)/(1-x))$. It gives the upper bound $A_n(x)+x^{2n+1}/(1-x^2)$. The denominator is positive throughout the stated range.
