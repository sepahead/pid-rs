# Fixed-source replay decision

The objective is to reproduce the eleven already accepted original finite categorical
MGW target-copy targets. This operation changes no theorem, import, premise, allowed
axiom, or scientific acceptance rule. The complete project closure has 17 modules.
The new attempt has no inherited execution credit or reusable old registration.

| Route | Decision and boundary |
|---|---|
| Retain the existing receipts without executing | Valid historical evidence; does not provide a fresh project rebuild. |
| Recheck only receipt hashes | Useful for preservation; cannot execute proof terms. |
| Compile only Bounds using prior project objects | Repeats the existing dependency assumption; insufficient for the selected fresh-source objective. |
| Compile all project sources without judges | Rebuilds proof terms but omits the required full original target-name/type and axiom reports. |
| Compile all sources and all judges | Necessary baseline; still lacks fresh-environment replay. |
| Run non-fresh leanchecker | Rechecks module declarations against imported environments; weaker import-environment scope than selected. |
| Compile all sources and use fresh leanchecker on Bounds | Selected: Bounds transitively imports all eleven proof exports, with the three judges compiled separately. |
| Use fresh leanchecker on a judge module | Adds meta code but does not rerun run_cmd. It gives no useful substitute for separately compiling the judges. |
| Rebuild every external dependency and compiler | Distinct source-to-binary project; unnecessary to this explicitly assumed installed-dependency replay. Reconsider if correspondence or installation trust is claimed. |
| Use an independent kernel implementation | Valuable additional assurance; requires a compatible, separately reviewed toolchain and controls. The current Lean kernel is not that implementation. |
| Translate the problem to another prover or solver | Independent mathematics may help, but this would be a new formal object needing its own correspondence proof. |

The selected route freezes exact source and stdout hashes before registration. It
rebuilds 17 modules from an initially empty project object directory, executes the
three original judges, and requires the same complete reports. A final
`leanchecker --fresh PidMgwTargetCopyCandidate.Bounds` adds fresh-environment
same-kernel evidence. New output objects are retained and must not change between
commands. Each compiler has 120 seconds; the fresh replay has 300 seconds. The
campaign has 1,800 seconds, one native command at a time and no retries.

Root inspected installed `LeanChecker.lean` and `Lean/Replay.lean` on 11 September.
The former imports the selected module and replays its environment constant map
into an empty environment. The latter skips unsafe and partial constants, adds
axioms as declarations, checks theorem values and definitions through the kernel,
and compares constructors and recursors with reconstructed inductives. It does
not establish axiom truth or enforce this project's axiom allowlist. The original
judges supply the latter and complete-target checks. Compiling those judges
executes their run_cmd blocks; replaying their objects would not repeat those blocks.

Selected executables and source files are freshly hashed. External installed
objects, dynamic libraries, Python and operating-system runtime remain declared
assumptions. This is not a complete installed-profile re-observation, load trace,
atomic snapshot, independent kernel implementation or proof of source-to-binary
correspondence. Sampled resource limits are not hard process containment. The
existing reviewed runtime's source-loaded Runner is used without alteration; its
unrelated preparation and legacy scientific routines are never called.

The independent review identified an inherited cleanup limitation: after polling
reaps the leader, this runtime refuses to signal the old process-group ID. A
remaining in-group descendant is reported as failure but may remain alive. The
selected operation requires empty per-call final group observations and a separate
post-run process-ownership inspection. Those observations do not prove general
command-tree termination or containment. A failure stops this attempt; it is not
permission to rerun or accept the next command.

The earlier scope council's ten routes and fifty named lenses remain the scientific
coverage review. This narrower route decision adds the actual replay implementation
inspection. A new independent driver review is requested before native entry.
All review is model review; no human or institutional review is claimed.
