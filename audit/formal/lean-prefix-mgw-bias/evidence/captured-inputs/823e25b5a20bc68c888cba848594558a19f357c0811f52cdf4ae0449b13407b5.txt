It uses the unchanged runtime bytes and actual checked helper load. The fake Runner records exact named invocations and writes unmistakably inert object bytes. A Python audit hook denies external process creation inside the driver and refuses external bias candidate reads. The outer supervisor uses the unchanged bounded runtime to launch only the control Python driver. This is scoped instrumentation, not an adversarial-host sandbox.

Production `campaign.py` and `close-campaign.py` reject a `SYNTHETIC_CONTROL_ONLY.json` marker. Each fixture pins that marker in its freeze. Consequently a fixture cannot be run as a live adopted lane: leaving the marker rejects at the guard; removing it invalidates its frozen inputs. Only the source-bound trace driver instruments that exact guard, records the action, and retains zero proof credit. The corresponding unpatched refusal controls are mandatory. No environment variable, CLI test bypass or alternate production validator is introduced.

Synthetic candidates consist only of inert `True` grammar fixtures, and their synthetic semantic records explicitly identify themselves as parser fixtures. The strict closure baseline is generated by the instrumented actual runner, with one retained failed development attempt, one successful diagnostic attempt, selected normal/optimized full routes, actual instrumented wrong-final, and cosmetic normal/optimized full routes. Its seven attempts are not Lean proofs. Closure instrumentation bypasses only the synthetic guard; it does not replace validators, evidence readers or policies. Each mutation preserves a baseline manifest, content-addressed before/after bytes, actual child streams and a driver receipt. One marked inert fixture is restored between cases to preserve absolute source/command paths and avoid unnecessary full copies; every restoration is scoped to that fixture. Generated synthetic acceptance/STOP bytes are archived as `SYNTHETIC_*`, and receive zero acceptance credit.

Candidate symlink/hardlink refusals retain actual pre-invocation filesystem metadata and child evidence. After the rejection, only those inert links are materialized or unlinked so that the final control artifact inventory consists of canonical single-link files. This retention conversion is explicit; it is not a claim that a symlink remains present after the control.
