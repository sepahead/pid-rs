# Source correspondence and retained evidence

This package preserves the project source closure and permitted execution evidence for **five locally accepted finite categorical MGW bias families**. It is a source/evidence publication proposal. No relocated proof run, current portable replay engine, hosted pass or produced PDF is supplied by this packaging stage.

Start with the [exposition](EXPOSITION.md), [summary](SUMMARY.md) and [theorem-to-proof map](THEOREM_MAP.md). The [run results](RESULTS.md) explain selection and retained failures. The [future replay obligations](REPLAY_OBLIGATIONS.md) separate the next operational work from the original acceptance.

## Exact object and source closure

The object is the finite categorical shared-exclusions PID fixed to [MGW arXiv:2002.03356v5](https://arxiv.org/abs/2002.03356v5), in nats, and the project's specified prefix statistic under a normalized nonnegative complete-row population law. A fresh independent anchor and a fixed number of further iid complete rows define its native finite-product expectation. Dependence within each row is unrestricted. This is a formal probability result; the package introduces no Rust/Python estimator implementation or statistical calibration claim.

The exact selected candidate is [Candidate.lean](sources/PidPrefixMgwBias/Candidate.lean), SHA-256 `c945862f2bb64825ad5b754cd6fcd4f32da02c0377f13074d9192b6568e3fb45`. Its [Contract](sources/PidPrefixMgwBias/Contract.lean), [RawTargets](sources/PidPrefixMgwBias/RawTargets.lean) and [AliasTargets](sources/PidPrefixMgwBias/AliasTargets.lean) retain the accepted bytes and complete quantified assumptions. The Contract's proposal/unproved header is an unchanged historical comment from type preparation; the later selected candidate and acceptance supply the proof status.

[SOURCE_CLOSURE.json](SOURCE_CLOSURE.json) gives the exact module order, sizes and hashes:

- 24 inherited project modules, copied from the already prepared mean public package and compared byte for byte with the accepted bias-campaign sources;
- three bias type modules;
- the selected candidate, its actual semantic judge and the final kernel root.

Thus there are 27 dependency/type modules before the candidate and 30 project compiler modules in a successful full run. The full source set is included locally, so inspection does not require the sibling mean package. The sibling correspondences document reuse; they do not count as new proofs. Complete Lean, Mathlib and upstream package installations are separate pinned dependencies, described in [UPSTREAM_PINS.json](UPSTREAM_PINS.json) and the captured [toolchain files](toolchain/lake-manifest.json).

The five exports are `actual_finite_bias`, `fiber_inverse_moment`, `support_moment_bounds`, `projected_support_bias` and `mass_floor_bias`. The fiber export has two universe parameters; the others have three. The permitted proof axioms are `Classical.choice`, `Quot.sound` and `propext`. The source semantic judge checks actual theorem types and axiom closures. Public declaration aliases and 36 private proof steps are not additional scientific families.

## Raw bytes and public projections

[SOURCE_PUBLIC_MAP.json](SOURCE_PUBLIC_MAP.json) is a per-input correspondence map. Each entry records the original logical source key, original byte length and SHA-256, public path, public byte length and SHA-256, and whether that public file is byte-identical or a projection. Original raw hashes inside preserved receipts continue to name the original execution bytes. They have not been rewritten to pretend that a public projection was executed.

The logical locator `historical-campaign` refers to the accepted campaign domain in that map; `historical-project` identifies original project inputs; `reviewed-lean-4.33.0` names the historical tool installation role. These are descriptive locators, not filesystem paths or a replay command. Public links in this document resolve to the packaged sources and records. Private roots and host filesystem identity vectors are excluded from public receipt projections; any omitted JSON fields are listed in the map. Device-wide process lists, user prompts and session handoffs were not copied.

Safe source and stream bytes are retained unchanged. A diagnostic stream containing a private source path has a marked public path projection, while its exact original bytes and raw digest remain retained locally. The ignored private correspondence map locates those originals for the maintainer; it is outside the public payload. A future restricted archival deposit needs its own approved location and retention evidence. No off-host durability of private raw preimages is claimed here.

Files under `evidence/captured-inputs/` use the original captured-input digest as their identifier. When their map entry says `public_projection`, that filename is **not** the hash of the projected contents; the separate `public_sha256` is. Repeated original inputs can map to one preserved content object. No normalization is applied to accepted Lean source bytes.

Historical operational Python sources and attempt-specific Lean snapshots are kept as `.txt` inspection files. They describe the original route and its failures; they are not a newly authorized replay implementation. The explicit `sources/` graph is the proposed compiler input set for a future separately reviewed replay. The `formal/` copies retain the earlier publication's inspection filenames and exact bytes.

## Bounded coverage and omissions

The package maps every one of the 2,450 input entries in the original root acceptance: text inputs have public counterparts, and binary/cache inputs have entries in [OMITTED_INPUTS.json](OMITTED_INPUTS.json). The 615 omitted entries include repeated captured objects; that number is not a count of distinct tools or caches. None of those originals was deleted. The omission list preserves their recorded sizes and hashes.

All ten attempts retain original and executed candidate snapshots, complete recorded source snapshots, command/registration records and both compiler/kernel streams. The public receipt projections preserve outcome, timing, command arguments under logical locators, resource observations, dependency records and decisive diagnostics. [RUN_INDEX.json](RUN_INDEX.json) identifies the original and public receipt hashes separately.

The eight original preparation-control summary receipts are included. The much larger preparation-control artifact trees are retained in the original closed lane and are explicitly omitted from this proposal. This package is not a fresh re-examination or relocated execution of that complete control corpus. Binaries, compiled `.olean` objects and upstream caches are omitted. Their historical identities are evidence about the old runs, not a supplied executable environment or authentication of those tools.
