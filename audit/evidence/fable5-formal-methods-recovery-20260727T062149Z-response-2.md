# Hostile review — floating-point & compiled-refinement lane

**Role boundary.** I attack the binary64 measurement layer, the compiled Rust dataflow, and every bridge between "theorem about a real-valued DAG" and "bytes a linker produced." I defer Lean-kernel internals, Mathlib trust, and deep statistical methodology to the reviewers assigned there, raising them only where they intersect my lane. Nothing below is an endorsement of anything I did not explicitly check a design for.

**Top findings (each expanded below):**

1. The `32*EPSILON` gate is currently *luck-scoped to the corpus*. A provable universal bound exists and is cheap: pin the four-term association to paired differences and you get a **≤ 28ε absolute bound for all magnitudes < 16** (covers `D ≤ H_{n−1} < 14.4`, i.e., n up to ~10⁶) by ½-ulp stack-up, Gappa-checkable with Coq/Flocq proof export. The naive left-to-right association only stacks to **36ε > 32ε** — your gate sits *between the two associations*, which is exactly where compiled-refinement bugs live.
2. The four nonendpoint collisions at rejected prime 1,000,003 are **statistically impossible under the stated model**. Expected collisions ≈ 7,844/1,000,003 ≈ 0.0078; P(≥4) ≈ 1.6×10⁻¹⁰ under Poisson. Either the corpus has duplicate/symmetric rows sharing one numerator (e.g., x↔y mirrors and W1/W2 re-encodings: 4 = 1 value × 4 encodings), or the numerators have arithmetic structure, or the modular reduction has a bug. Until root-caused, the fault-diversity claim for the three accepted primes is not calibrated.
3. The frozen-corpus FP gate is **exactly decidable in integer arithmetic**: `|t̂ − p/q| ≤ 32ε` for a concrete double `t̂` and rational `p/q` is a pure integer inequality. No Decimal, no MPFR, no FP measurement is needed to check it. The Directed-Decimal route should be demoted to a diversity cross-check or retired; it adds correlated complexity to the trusted cut.
4. **Sign/zero decisions on T must never be FP-based.** Nonzero |T| has no useful lower bound: T = Σ_{i=y}^{n−1} 1/i − Σ_{i=k}^{x−1} 1/i, and near-multiplicative coincidences `xy ≈ kn` heuristically drive nonzero |T| to ~1/(kn) ≈ 10⁻¹² and, with second-order tuning, plausibly below 32ε ≈ 7.1×10⁻¹⁵. In contrast, endpoint separation is provably safe: nonendpoint rows satisfy min gap ≥ 1/(n−1) ≥ 10⁻⁶ ≫ 60ε. Formalize the second; forbid the first.
5. **Kani and CBMC are one engine, not two.** Kani's backend is CBMC. Counting them as failure-diverse routes is a correlated re-encoding. Genuine diversity for compiled refinement: Kani/CBMC (bit-blasting) vs. Miri (MIR interpretation) vs. Gappa/Flocq (symbolic real-vs-rounded) vs. cvc5 SMT-FP with independently checked proofs.
6. The γ premise is heavier than needed. The four-term T cancels **any** additive constant; the theorem needs only the recurrence hypothesis `ψ(m+1) = ψ(m) + 1/m` (m ≥ 1). Restate the Lean theorem with that hypothesis and γ leaves the trusted cut entirely; the analytic identification with real digamma stays where it belongs — in the declared estimand semantics.

## 1. First-principles reconstruction audit

Ways to silently reconstruct the wrong object, with fail-closed checks:

- **Patch fuzz drift.** `git apply`/`patch` accept hunks at offset with fuzz; after reordering waves, a hunk lands in the wrong place and still applies. *Check:* full-index binary patches only; apply with `--check` and zero fuzz; record **post-state blob and tree hashes per wave** in the manifest; replay must reproduce the exact tree hash (`git rev-parse HEAD^{tree}`) or halt. File-level hashes are insufficient — a renamed file passes content matching but breaks path-sensitive builds; require tree-object equality plus empty `git status --porcelain=v2`.
- **Transcript-as-oracle.** Replaying recorded command *outputs* into files resurrects stale generated artifacts (old toolchain, old RNG state, old thread interleaving). *Rule:* transcripts certify intent; only source edits replay; every derived artifact is regenerated and hash-compared to transcript-recorded values, mismatch ⇒ quarantine, never overwrite.
- **Generator self-consistency trap.** A regenerated view matches its regenerator because both drifted together. *Check:* frozen views are compared against the hash frozen *at freeze time*, together with the generator-source hash frozen alongside; any mismatch triggers investigation with a version bump and changelog — **never silent re-freezing**. For views that are themselves scientific objects (the 8,198-row corpus), require a second independent generator.
- **Snapshot/GC hazards.** Alternate-index snapshots capture tracked files only; frozen inputs outside git (tables, corpora, kd-tree caches) vanish silently. Unpushed snapshot refs die to `gc`/reflog expiry; `/private/tmp` on macOS is actively cleaned (you learned this). *Checks:* refs under `refs/snapshots/*` pushed to a remote after every wave; `git bundle verify` + scratch clone + `git fsck --full --strict` per bundle; a manifest enumerating **all** external artifacts with sha256+size, verified with `shasum -c --strict` where a missing file is a failure, not a skip.
- **Environment drift (my lane's core).** Pre-loss FP bytes were produced by a specific rustc/LLVM/libm/target tuple. Reconstruction on a different tuple can change: libm-backed functions (glibc vs. musl vs. Apple), codegen-unit partitioning (binary hashes), `target-cpu` feature selection, and — if any dependency compiles C with fast-math — reassociation. *Checks:* record `rustc -Vv`, `Cargo.lock` hash, target triple, build flags in the manifest; settled-byte claims are **scoped per environment tuple**; add a runtime probe asserting MXCSR FTZ/DAZ (x86_64) / FPCR FZ (aarch64) are clear — a stray shared-library constructor setting flush-to-zero silently changes subnormal behavior. Audit FFI dependencies' build flags for `-ffast-math`.
- **Filesystem semantics.** APFS NFD filename normalization, `/tmp` ↔ `/private/tmp` symlink aliasing (double-counting or missing paths in manifests), `core.autocrlf`, tar metadata nondeterminism. *Checks:* canonical `git archive` for tarballs; NFC-normalize manifest paths; ban autocrlf repo-wide.
- **Cache resurrection.** Reconstructed runs can agree with pre-loss *wrong* bytes via stale caches (cargo incremental, memoized tables, serialized kd-trees). Your "no pre-loss run is final" policy is right; extend it: purge `target/`, all memo caches, and rebuild `--locked` from clean.

The stated policy (durable worktree, per-wave snapshots, bundles, push-every-milestone, machine-readable manifest, full gate rerun) is sound. The gaps are: tree-hash rather than file-hash matching, external-artifact coverage, environment-tuple scoping, and zero-fuzz patch application.

## 2. Formal-method portfolio (ranked; each closes a distinct obligation)

**A. Exact-integer gate decision (MUST).** Obligation: corpus FP gate verdicts. `t̂` is a concrete bit pattern; `p/q` exact; `|t̂ − p/q| ≤ 32ε` ⇔ `|t̂·q·2⁵² − p·2⁵²| ≤ 32·q` in integers. Trust base: one bignum stack; add a second (GMP vs. `num-bigint` vs. Python int) for diversity — byte-agreement required. Bridge: trivial (bits in, integers out). Bounded: per-row. Mutation: poison one row's `t̂` by 1 ulp ⇒ both stacks flag. Rejection: any inter-stack disagreement halts the phase.

**B. Correctly-rounded harmonic table, integer-certified (MUST).** Obligation: table entries `h_m = RN(H_m)`. H_m is *rational* — correct rounding is decidable by pure integer comparison against the rounding boundary (compare `2p·2^e` with `(2m̂+1)q`). No MPFR needed; do not import transcendental machinery for a rational object. Store the table as **u64 bit patterns with a checksum**, not decimal literals. Cost note: exact incremental p/q to m = 10⁶ is heavy (denominators ~4×10⁵ digits); use 128–192-bit fixed-point directed rounding with per-entry error ≪ boundary gap, escalating to exact rationals only for near-boundary entries. Mutation: flip one entry's low bit ⇒ checksum gate and certification both fail. Rejection: any entry not certifiably correctly rounded blocks the table.

**C. Gappa bound on the pinned association, Coq-exported (MUST).** Obligation: universal combine-step bound. With table hypotheses ≤ ½ulp and magnitudes < 16: paired association `(h_{k−1} − h_{x−1}) + (h_{n−1} − h_{y−1})` stacks to 4·4ε + 2·4ε + 4ε = **28ε**; naive `((h_k+h_n) − h_x) − h_y` stacks to 16ε + 8ε + 8ε + 4ε = **36ε**. Gappa will likely tighten both (Sterbenz cancellations); export the Coq/Flocq proof so the tool leaves the trusted cut. Bounded: magnitudes < 16 (doubles per binade if the domain grows); RNE only; no FMA. **Semantic bridge is the weak link**: prove the binary implements this DAG via (i) single-source generation — one DAG spec emits both the Rust code and the Gappa script (mutate the spec ⇒ both fail), and (ii) a Kani bit-equality harness between the shipped helper and a straight-line reference on symbolic inputs. Mutation: reassociate the code ⇒ bit-equality gate fails. Rejection: any Gappa hypothesis unverifiable against B's certificates.

**D. Kani (CBMC backend) for integer/dataflow invariants (MUST).** Obligations: `k−1 ≤ nx,ny < n`; `x = nx+1` map; inclusive-path passes x directly (no accidental +1); tie/ε=0 fail-closed guard; panic/overflow freedom (with `overflow-checks=on` even in release — Rust release wrapping is defined but silently wrong); no NaN propagation given NaN-free ingest; ±0 insensitivity of counts. Bounded: small n, d; floats bit-blast expensively — constrain exponent windows. Mutation: seeded mutants per invariant (`<`→`≤`, off-by-one on each of four indices, both directions — that's 8+ mutants for the index map alone). Rejection: any surviving mutant means the harness doesn't bind. **Do not book CBMC as a second route** unless there is C/C++ FFI; Kani *is* CBMC.

**E. Flocq/Rocq generic lemmas (HIGH-VALUE; MUST if any runtime summation survives).** Obligation: association-closed bound for parallel/reordered sums — for *any* binary tree over m terms, |fl(Σ) − Σ| ≤ γ_{m−1}·Σ|aᵢ|. Sharp consequence you should publish: **naive recomputation of H_m meets 32ε only for m ≤ 11** ((m−1)·H_{m−1} ≤ 32 fails at m−1 = 11). This is the theorem that forces the table architecture. If a compensated path is ever used, take the proven 2Sum/FastTwoSum EFT lemmas (FastTwoSum's exponent precondition matters). If the code-path inventory shows table-only, downgrade to optional.

**F. cvc5 with proof production + independent checker (HIGH-VALUE).** Obligation: replicate the four Z3 QF_UFLIRA obligations with Alethe/LFSC proofs checked by carcara/lfsc-checker — removes the SMT solver from the trusted cut, replaced by a small checker. Also bit-precise QF_FP micro-lemmas: signed-zero production sites (`(−0)−(+0) = −0`; `a−b` for a=b finite yields +0 in RNE), comparator/tie logic, and extremal queries (§3). Correlation note: shares the IEEE model with Gappa — diverse engines, correlated semantics; say so in the shared-cut ledger. Mutation: the 12 SAT mutants must stay SAT with models replayable by a ~50-line evaluator.

**G. Arb/MPFR interval certificates (HIGH-VALUE).** Third diverse numeric stack; per-instance only, no universality; the escalation tool for near-boundary rounding decisions in B. Rejection: any ball that fails to separate at max precision escalates to exact rationals or halts.

**H. Miri + sanitizers (HIGH-VALUE, cheap).** UB invalidates every FP theorem about the binary. Different failure class from everything above.

**I. Verus/Creusot (OPTIONAL).** Functional kd-tree correctness for arbitrary n. Their FP story is weak; scope to integer/structural properties. Expensive; only worthwhile if the kd-tree is a permanent load-bearing component beyond what D covers at small n.

**J. TLA+/Alloy phase machine (OPTIONAL).** Model the NO-GO/gate ordering; invariant "no integration before all gates closed"; mutation: delete a gate edge ⇒ model checker finds the violation. Process assurance, not proof of arithmetic.

**K. Rejects.** Proof-producing SAT via whole-helper bit-blasting (blowup; F covers it); more primes for the modular certificate (diminishing, correlated — and pointless until finding #2 is root-caused); random-float sampling as bound evidence; any fast-math anywhere; GPU reductions inside settled-byte scopes.

## 3. Evolutionary / CEGIS route

Search spaces that pay, each with an exactification pipeline:

- **Sub-gate nonzero T (the big one).** Space: (k,n,x,y) with `xy ≈ kn`. Since T ≈ ln(kn/xy) − (1/(2n)+1/(2k)−1/(2x)−1/(2y)) + O(k⁻²), pick integer δ = xy − kn canceling the first-order terms, then locally tune (x,y) factor pairs. Heuristic reach ~1/(kn) ≈ 10⁻¹², plausibly lower with second-order tuning. Every candidate is **decided exactly** (integer route A); hits become corpus rows and, if any lands below 32ε, they are the definitive demonstration that FP sign/zero classification is unsound (finding #4). Search failure proves nothing: the space is ~10²⁴ tuples and the objective landscape is deceptive; log budget/seed/coverage as a negative result, no theorem credit.
- **Association adversary.** For the four-term helper the space is tiny: 5 tree shapes × leaf permutations ≈ 75 distinct evaluations modulo commutativity — **enumerate exhaustively**, don't search. Compute the exact error of every association on the corpus; publish the table; pin the code to the best-bounded association (C). For long reductions (means over rows, table generation), GA over permutations/trees maximizing |fl(tree) − exact| yields regression inputs; the *general* claim is then E's any-tree lemma, not the search.
- **Geometry adversary for W1/W2.** Space: ≤ 8 points, coordinates from dyadic grids ± `nextafter` perturbations, duplicates, ±0, subnormals, exact-boundary distances (powers of two so max-norm distances are exact). Fitness: brute vs. kd-tree count mismatch; unflagged ε = 0; count-domain violations. Minimize by delta-debugging to ≤ 3 points; snap to exact dyadics reproducing the branch trace; then generalize with a Kani harness constrained to a neighborhood of the witness. Product: permanent witness-corpus entries, not anecdotes.
- **Candidate identities.** Mine the corpus for coincidences (e.g., does T = 0 occur only at {x,y} = {k,n}? does `2H_{x−1} = H_{k−1} + H_{n−1}` ever hold?). Each candidate goes to exact search over bounded ranges, then to a number-theoretic proof attempt (2-adic valuation of H_m is the natural tool) or a counterexample. Status stays "conjecture" until Lean-proved; do not let corpus-verified identities leak into theorem language.
- **Mutation-resistant invariants (CEGIS).** Template grammar over (k,n,x,y,counts): linear inequalities, monotonicity, symmetry. Verify candidates with integer SMT/QF_FP; counterexamples refine. Only solver-verified invariants ship; simultaneously run a mutation engine over production and require the invariant suite to kill every arithmetic/comparison mutant or document a proven equivalence. Publish the kill matrix — 14 mutations across 19 Lean theorems is thin; the main inequality alone needs ~10 mutant classes (four indices × two directions, x↔y swap, ≤→<, dropped `1 ≤ k`, dropped `n ≥ 2`, reinstated γ dependence).

## 4. KSG closure attacks

- **Exact theorem.** The bound −D ≤ T ≤ D with tightness at (k,k)/(n,n) is correct given the domain; the attack surface is the *premise and domain plumbing*. (i) Replace the γ-laden premise with the recurrence hypothesis (finding #6); a hostile reader currently sees γ in the cut for no mathematical reason. (ii) Nat-subtraction: if Lean states indices as `m − 1 : ℕ`, k = 0 is silently truncated, making the hypothesis `1 ≤ k` load-bearing — demand a mutant that drops it and check the proof fails rather than proving a vacuous or wrong statement.
- **Index maps.** W2 must pass x directly; the deadly mutant is a stray `+1` on the inclusive path pushing x = n+1 out of domain. Production must contain an explicit domain check that *fires* on a crafted dataset (presence-of-guard test), because the theorem says nothing outside `k ≤ x,y ≤ n`.
- **Ties break the refinement.** With k duplicated points, the kth joint distance is 0 and marginal counts collapse: nx = 0 < k−1, x = 1 < k — **the theorem's hypotheses are violated by real data**, and "continuous support is declared" does not make ties impossible in inputs. The ε = 0 / count-domain guard is a proof obligation (D), not hygiene. Bootstrap resampling *guarantees* ties, so the guard will fire by design there (see §6).
- **Modular implication.** The sound direction is: nonzero residue ⇒ nonzero rational ⇒ nonendpoint. Zero residues at three primes prove nothing; the exact route is the decider and the primes only guard against independent bignum corruption. Audit every sentence for direction. Then root-cause finding #2; predicted explanation: deduplicate symmetric/W1-W2-mirrored rows and the "4 collisions" collapses to 1 unlucky numerator. If the four rows are genuinely distinct values, suspect the reduction code (e.g., a shared factor between numerator pipeline and p) before believing 1.6×10⁻¹⁰ luck. Also verify the design invariant that makes residues well-defined: all denominators' prime factors ≤ n−1 < p — this silently caps corpus n; state the cap.
- **FP measurement language.** "Exactly 8ε" (rounded reference, 40 rows) vs. "< 9.761311ε" (exact, different unique maximizer) is only consistent under specific metric normalizations; as written, a reader can't reconcile them with the triangle inequality (|helper − exact| ≤ |helper − ref| + |ref − exact|). Publish the exact metric definitions (absolute error in units of ε = 2⁻⁵², per-row scale/binade, reference = RN(exact) or directed Decimal with quantum δ) and a machine-checked lemma tying the two. The 40-row and 4-collision multiplicities smell like the same duplication structure — check once, explain both. Never report relative error near T = 0 (finding #4). Rename `32ε` from "gate" connotations of *bound* to "corpus-scoped acceptance threshold" until C lands, after which it becomes theorem-backed for the pinned association.
- **Endpoint classification.** Structural classification (integer-side) is right; add the cheap separation theorem: nonendpoint ⇒ distance to nearest endpoint value ≥ 1/(n−1) ≥ 10⁻⁶ ≫ 28ε + 32ε. Kill the mutant that classifies via `t̂ == d̂`.
- **W1/W2 production refinement.** Attack list: kd-tree pruning comparator vs. count comparator at exact boundary equality (`<` prune with `≤` count is the classic silent bug — dyadic-exact witnesses required in every dimension); self-exclusion consistency with `nx < n`; NaN ingest (a `partial_cmp().unwrap()` panics fail-closed — good; `total_cmp` silently orders NaN — audit which is used); −0/+0 at the coordinate layer (distances via `abs` are fine, but `f64::max(−0.0, +0.0)` is not specified to pick a sign — irrelevant numerically, lethal to settled-byte hashes; canonicalize −0 before hashing/serialization and document NaN rejection); FTZ/DAZ probe (§1); parallel reductions must be integer-only (counts commute) — any FP accumulation across points needs a fixed reduction tree or it breaks both determinism and E's bound scope.
- **Release/custody.** Settled bytes on *binaries* require reproducible-build discipline (`codegen-units=1`, `--locked`, pinned toolchain, SOURCE_DATE_EPOCH); otherwise gate on outputs. Cross-platform settled-byte claims for FP outputs are ill-posed unless the FP path is libm-free and table-driven with embedded bit patterns — which the B+C architecture delivers; scope claims per target triple regardless. Custody/receipt layers are process controls; they bound *who changed what*, not correctness — don't let them appear in the trusted cut of any theorem.

## 5. PID2 and MGW SxPID3 forward design (two failure-diverse routes per obligation)

- **Firewall mechanics first.** Every evidence row carries an object tag (KSG-int, KSG-cont, Ehrlich-cont, MGW-cat, I_min, quantized); any row citing two tags must cite a mapping-theorem id; the schema checker rejects forged cross-tag rows (test this with a seeded forgery). Maintain a **distinguishing corpus**: inputs where I_min, Ehrlich, and MGW provably differ. If two implementations ever agree on all distinguishing rows, you have a wiring bug, not a discovery — this is the cheapest anti-conflation alarm available.
- **PID2 represented-sum rev4.** Route 1: Lean proof of the represented-sum identity over ℚ (symbolic, float-free). Route 2: executable exact-rational evaluator on a second bignum stack, exhaustive over small alphabets (2×2×2 up), randomized beyond, checking Möbius-inversion consistency and the represented-sum against the direct definition. Negative atoms: include distributions with known negative shared/synergy atoms; inject a clamp as a mutant — the suite must fail loudly. MI inputs unclamped: mutant that clamps MI at 0 must also be killed.
- **MGW SxPID3 values.** Atoms are ± sums of logs of rationals: represent as Σ qᵢ·ln rᵢ with qᵢ, rᵢ ∈ ℚ. Route 1 (symbolic-exact): sign/ordering decisions reduce to comparing rational power products to 1 — pure integer arithmetic, exact, preserves negative atoms by construction. Route 2 (numeric): Arb ball evaluation with precision escalation until separation, halting to Route 1 on exact ties. Disagreement ⇒ bug, by construction. If any component is optimization-defined, use exact rational LP with **primal/dual certificates** checked by an independent ~100-line inequality verifier — that pattern (certificate + tiny checker) beats trusting any solver.
- **108-coordinate binding.** The binding object must be a machine-readable **coordinate registry** (ordered ids + definitional hashes), generated by two independent implementations (different authors/languages, e.g., a Lean/Coq enumeration of the trivariate lattice vs. a Rust one) that must byte-match. Programs A–E each consume the registry *hash*; mutants that permute two coordinates, drop one, or duplicate one must fail **all five programs** fail-closed. Do not claim "all 108 bound" from prose — I cannot verify the count from first principles and neither can a reader; the registry hash is the claim. Warn explicitly: if Programs A–E share one enumeration library, they are five correlated re-encodings, not five routes; require at least two disjoint enumeration stacks.
- **Lattice-failure search.** Enumerate small distributions violating any *claimed* lattice inequality (negative atoms are valid, so first pin down which inequalities are actually asserted per object; asserting none is a legitimate answer that must be recorded as such).

## 6. Statistical theorem discipline

Separate ruthlessly; only the first column is theorem-eligible:

- **Formalizable:** estimand definitions (MI under declared continuous support; `I(X+ε;Y)` as a *different* estimand — the noise-changes-estimand rule is a definition, encode it as one); the integer/rational arithmetic layer (done/§4); the endpoint-separation bound; resampling-class *definitions*; the 28ε combine bound.
- **Empirical only, forever:** KSG bias/variance at finite n; calibration coverage; corpus error maxima; prime-collision statistics. Discipline: pre-registered simulation grids on families with known MI; seeds and environment tuples in the manifest; multiplicity control named and fixed in advance (BH or max-statistic permutation); dependence honored — per-point kNN contributions are correlated, so no naive CLT intervals; **subsampling without replacement, never bootstrap-with-replacement** (resampled ties force ε = 0 and the §4 guard fires by design — document this as intended behavior, not a crash).
- **Language police:** a lint over papers/PDFs flags "universal," "for all," "bound" in any sentence not carrying a theorem id; empirical claims must carry scope tuples (family, n, k, seeds). This is the enforcement mechanism for "bounded evidence never promoted universally," which otherwise decays into style guidance.

## 7. Machine/human/PDF parity

**Schema (JSON/CBOR):** entities `Obligation{id, statement_hash, object_tag}`, `Assumption`, `Evidence{kind ∈ {lean, cvc5, z3, gappa+coq, arb, integer-gate, kani, miri, test, simulation}, toolchain_hash, cmd, input_hashes[], scope, verdict, resources{cpu,mem,wall}, seed}`, `NegativeResult{budget, seed, coverage}`, `Gate{status}`, `SharedCut{members[]}` (e.g., "IEEE-754 model: Gappa+cvc5-FP+Kani"; "CBMC engine: Kani"), `Mapping{theorem_id}`, `FailedRoute[]` (mandatory: nonempty or explicit attested "none"). Linter invariants: every obligation has ≥1 evidence or an open gate; cross-tag evidence requires a Mapping; every bound has a scope; every evidence row has a replay command + environment tuple.

**PDF projection:** generated *only* from the schema; auto-generated assumption ledger, open-gates page, shared-cut ledger, resource table, and a manifest page of hashes; build fails on orphan claims (extract PDF text → claim ids → every technical sentence maps to an obligation id or is tagged narrative).

**Parity mutations (all must fail loudly):** delete an assumption from the schema ⇒ PDF build fails, not silently omits; edit PDF text post-build ⇒ detached hash/signature check fails; upgrade a scope to "universal" without a theorem id ⇒ linter fails; delete a FailedRoute ⇒ attestation check fails. **Page-review mutations (calibrate the humans):** seed review copies with (a) two swapped theorem statements and (b) one altered manifest digit; record reviewer detection rates. A human gate that has never caught a seeded fault is an unmeasured instrument.
