The captured table has five distinct retained `(S1,S2)` pairs, not all source
pairs: `(S2,S3)=(29,28)` repeats three times. Four supported states are not
four independent bits. A normalized event union is not generally an operand
or intersection; degenerate maps can make them equal. Inconsistent anchors
can invalidate identities, while a consistent common replacement preserves them.

Root review caught an exact-expression error in the independent duplicate
packet: copied-minus-single smoothed loss is `(1/4)ln(625/648)`, not
`(1/4)ln(625/1296)`. The old decimal losses and sign were correct. The erroneous
report, route record and JSON remain unchanged, with an appended derivation
and rational recheck. The same model's twelve routes and sixteen lenses had
not caught that expression-to-calculation mismatch. Do not use counts as proof.

does not bound every rare local value; small decoder error without alphabet
control need not imply small entropy. Oracle duplicate-input harm does not
imply every fitted model is harmed. All these counterexamples remain active.
