## Proof, assumption and observation

The named theorem declares the proposition its proof term inhabits. A source definition of a proposition supplies the statement. A typed example can show that a specific theorem satisfies a consumer's expected type. A successful `#print` or metaprogram can report data from the environment. The axiom report identifies assumptions recursively, and the fresh checker replays the loaded safe, nonpartial declarations into an empty kernel environment. Their inputs include previously compiled objects. The checks assume the installed binaries, loader and stable files. A source-to-object proof and external human review remain separate. The direction matters when transferring a theorem to a scientific claim. If every branch of family B contains a branch of family A, the Boolean formula for B implies the formula for A. For a fixed observation this gives the event inclusion from B into A. Recovering the order from observed events needs a domain realizing the relevant Boolean patterns. A one-point alphabet can make events from distinct families coincide. In the forecast theorem a tolerated fault and positive joint mass imply the displayed lower bound on a conditional probability. The named Lean reconstruction theorem assumes global factorization through the descriptor and one descriptor collision with unequal quantities. Equal assigned atoms on that pair already rule out a decoder for the two unequal quantities. These different antecedents have separate proofs and scientific meanings. ## Fault-tolerance receipt correction

The earlier standalone reader checked the toolchain text in the project, took its expected roster solely from the print commands and stored parsed rows by name. A shortened roster could report a shorter successful audit. A repeated name could replace an earlier record, and trailing diagnostic text could escape a prefix-only row match. The full reproduction script also compared the final report against its retained bytes. The revised reader checks the executing release and commit, requires the twelve original print commands in order, consumes each complete output record once, and accepts only the stated logical basis, including the genuine empty-basis form. The original and revised readers both emitted the same 1,157 bytes on the genuine study. Their SHA-256 is `0acf7a5714ca528cad28b239954f0abeb979ef1459644e083ee4164a23f7386d`. Reopen the comparison if the theorem, query roster, version grammar, compiler output grammar, imported libraries or admissible axiom set changes.
