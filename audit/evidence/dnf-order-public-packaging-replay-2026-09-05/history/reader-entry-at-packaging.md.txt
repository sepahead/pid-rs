# DNF and categorical event order

This standalone Lean lane checks thirteen statements about finite source collections and
categorical equality events. [Start with the exposition](EXPOSITION.md), then use the
[symbol map](SYMBOL_MAP.md) and [exact theorem table](SOURCE_CORRESPONDENCE.md).

The generic order is equivalent to reverse implication between monotone disjunctive normal
forms. Antichains have unique truth functions. Categorical events preserve this implication;
reflection on a restricted domain requires an explicit pattern-realization premise. Four fixed
counterexamples show why stronger claims fail. These statements do not establish an estimator,
atom-compression algorithm, sampling result, or application benefit.

[Candidate.lean](Candidate.lean) and [Contract.lean](Contract.lean) are the exact accepted bytes.
The [verification record](../../evidence/dnf-order-formal-verification-2026-09-05/RESULTS.md)
preserves all three failed full runs and the four successful source/mode combinations. The
original aggregate Lean project and its historical receipts remain unchanged.

## What the judge checks

The semantic judge compares each complete receiver-free theorem type against both a raw target
and a contract alias, checks its universe parameters and transitive axioms, and requires exactly
thirteen public declarations in `PidSxDnfOrderCandidate`. It parses thirteen structured records
and then runs `leanchecker --fresh SemanticJudge`. The candidate uses ordinary `decide`; the
kernel remains the final proof check. No new axiom or native-evaluation oracle is permitted.

Every Lean command uses `-t 0 -M 4096`. Each command has a 600-second timeout and a 4 MiB limit
for each output stream. Process-group memory is observed at 0.1-second intervals with a 4 GiB
threshold. Polling can miss an increase between samples. It is not a hard operating-system cap
on macOS. The original macOS `setrlimit` failure and the replacement are retained in the
[resource contract](judge-v3/RESOURCE_AND_EXECUTION_CONTRACT.md). Time, memory and output failures
are operational failures, not mathematical counterexamples.

`replay-v1.json` binds the new routing launcher, exact accepted source, unchanged judge payload,
and separate reporting helper. The [historical v3 freeze](judge-v3/frozen.json) keeps its original
after-candidate chronology and superseded run allocation. A new public replay does not alter
those historical facts or add independent-review credit to the completed campaign.
