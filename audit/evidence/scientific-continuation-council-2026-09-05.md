## Proposed DNF/order theorem

Let I be a finite source-index type. Let alpha and beta be finite families of finite subsets of I.
For a Boolean equality pattern e:I->Bool define

    E(alpha,e) iff there exists a in alpha such that every i in a has e(i)=true.
    alpha <= beta iff for every b in beta there exists a in alpha with a subset of b.

The proposed exact theorem is

    alpha <= beta  iff  for every e, E(beta,e) implies E(alpha,e).

The implication direction is deliberate: beta's event implies alpha's event. The theorem does not
require antichain or nonempty-family hypotheses. Those are separate carrier restrictions for PID.

Exploratory proof sketch:

1. Forward: if E(beta,e) has witness b, choose a in alpha with a subset of b. All coordinates in a
   are true because all coordinates in b are true. Thus E(alpha,e).
2. Reverse: fix b in beta and set e(i)=true exactly when i belongs to b. Then E(beta,e) holds with
   witness b. The assumed implication supplies a in alpha whose every coordinate belongs to b.
   Thus a is a subset of b.

The next corollary restricts to antichains. If both orders hold, alpha=beta: for a in alpha choose
b in beta with b subset of a, then a' in alpha with a' subset of b. The antichain property forces
a'=a, hence b=a. Repeat in the other direction. Equivalently, two antichains with the same DNF truth
function on every Boolean pattern are equal.

This result is classical finite monotone-Boolean/set logic. No novelty claim is made. Its value here
is the explicit correspondence among the exact MGW order, local predicate, and formal carrier.

For Fin 3, a bounded follow-on can define all nonempty subsets from powersets, filter nonempty
antichains, prove cardinality 18 and no duplicates, map each collection to its mask key, and prove
that the frozen 18-key registry is exactly this carrier. Define zeta entries from the proved order,
then check the stated integer inverse in both directions. Source-label equivariance should move
both subset labels and Boolean coordinates. It is distinct from reordering branches.

### Realizability falsifier

Do not replace the universal Boolean-pattern quantifier by patterns seen under one law.
Let all three source alphabets be singleton sets and choose their only source key as anchor. Every
equality pattern is then 111. Every nonempty family of nonempty collections has a true event.
In particular alpha={{1}} and beta={{2}} have identical concrete events, but neither alpha<=beta
nor beta<=alpha holds. An event-equality-to-antichain-equality claim is false in this setting.

The same failure can occur with binary ambient alphabets if comparison is restricted to a supported
diagonal law. The forward inclusion remains valid. The converse requires every separating Boolean
pattern to be realizable in the domain of comparison. An all-pattern semantic theorem avoids that
extra population premise. A concrete full-product event theorem can instead require at least two
values in each source alphabet and compare events on the full Cartesian product; positivity of
every pattern is not needed for set equality, but is needed for claims based only on positive-law
support. No implementation or source-paper defect follows from this falsifier.
