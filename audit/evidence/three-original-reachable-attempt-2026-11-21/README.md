# Three original proof checks stopped at call agreement

Sepehr Mahmoudian · 21 November 2026

**All three proposed proofs failed.** Each passed 22 module compilations, 22 fresh stock Lean checks and one separate check of a lemma about program prefixes. The next proof failed while Lean tried to construct a decision procedure. The limit on memory and the time limit were both respected. The run produced none of the 512 required pairs of assertion values. W02 remains the one completed stock Lean proof among the 22 original scripts for which the archived solvers reported an unsatisfiable formula. ## What the proofs had to show

A **script** is a sequence of commands. An **assignment** gives each input a value of its declared type. An **assertion** is a condition in the script. The question was whether the interpreter successfully returns both assertions in source order for every assignment, with at least one assertion false. An interpreter that stops without an answer gives no evidence that an assertion is false. A **prefix** consists of the first commands of a script. Each proposed proof compared a full prefix with one that kept only the input declarations and function definitions needed by the assertions. **Call agreement** means that looking up the same name in each prefix and applying it to the same arguments gives the same result. A **module** is a Lean source unit that can later supply definitions or theorems to another unit. A **fresh check** rechecks eligible declarations with the stock kernel in a new environment. An **axiom** is an assumption a proof can use. [Registered procedure](../../research/three-source-original-reachable-v3/README.md) · [Exact registration](../../research/three-source-original-reachable-v3-registration.json)

Each original has 89 commands and 25 typed inputs, including 16 integers with no upper or lower bound. The *projected* input keeps just one family code, or two cell keys. Each script requires both an exact result on that smaller domain and a proof that it agrees with the interpreter on every full assignment. The family codes represent sets of nonempty subsets of three sources. A valid family is nonempty and has no two distinct members such that one contains the other. This is a finite ordering question. It uses no sample, probability or information unit. [Original formula definitions](../../formal/finite-smt39-qualification-v1/README.md) · [Williams and Beer, Section III](https://arxiv.org/abs/1004.2515v1)

## Why the three cases stopped

The next lemma required equality of two calls for **every later prefix and every argument list**. Its proof tried to classify a prefix index by listing all its possible positions. W01 and W03 listed positions 1 through 82 after position 0. W15 listed positions 7 through 82 after position 6. In each file Lean reported that it could not construct the required `Decidable` instance at line 11, column 50. A `Decidable` instance supplies either a proof of a proposition or a proof of its negation. Lean also reported the unsolved call-equality goal. [W01 and W03 source](diagnostics/call-a.lean.txt) · [W15 source](diagnostics/call-k.lean.txt)

The compiler printed `[propext, sorryAx]` while recovering from each error. The submitted body contains no placeholder. The failed isolated command exited with code 1, emitted no compiled module and earned no accepted axiom record. W01 and W03 had byte-identical isolated source and diagnostics, with different original script inputs. Each has its own command and transition record. W15 has a different source, command and diagnostic. All three failed cases completed their custody checks. [W01 and W03 compiler output](diagnostics/call-a.stdout.txt) · [W15 compiler output](diagnostics/call-k.stdout.txt) · [Complete submitted proof bodies](submitted/)

Four deliberately false claims about invented programs produced their specified compiler errors. Four separate small scheduling tests checked single-CPU execution, a forced memory stop, a forced time stop and a succeeding worker. These tests checked the controls. They provide no assertion values for the three originals. The earlier original attempt stopped at a memory limit in W01 before starting W03 or W15. The later invented-program results and the intermediate unissued plan retain their own scopes.
