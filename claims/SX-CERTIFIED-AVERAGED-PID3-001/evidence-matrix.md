# Evidence matrix for SX-CERTIFIED-AVERAGED-PID3-001, revision 1

## Evidence rule

Evidence for one layer is not substituted for another. In particular, a correct finite lattice is
not a proof of event extraction; an exact rational product is not a real-log interval; a bounded
Python mirror is not compiled Rust refinement; and a deterministic empirical certificate is not a
population or calibration theorem.

## External bounded corpus corrections

The external report's bounded arithmetic observations are retained with these corrections:

1. `20,348` counts labeled weak count vectors, not distinct empirical probability laws.
2. `1,098,792` equals `20,348 * 54`; it covers informative, misinformative, and net atom values,
   not the 108 cumulative-plus-atom certificate registry.
3. A future complete bounded certificate replay has `2,197,584` averaged coordinate verdicts.
4. The reported second-path domain is 968 count vectors through total three and 52,272 values per
   path.
5. The same full count-vector corpus has 77,520 supported table--realization pairs; multiplying by
   54 atom/component coordinates gives 4,186,080 pointwise differential evaluations, all outside
   this averaged certificate claim.
6. The second script is partly diverse in antichain enumeration, matrix inversion, rational
   products, and floating evaluation order, but correlated at the imported event/count core.
7. Neither path executes the current compiled Rust API or proves an arbitrary-alphabet verifier
   theorem.

These corrections narrow the evidence claim; they do not erase the exact-zero residuals or other
bounded negative results.
