## Exact sign/zero census

Each classification compares one strictly positive exact rational product $Q$ with one:
$Q<1$ is negative, $Q=1$ is exact zero for the logarithmic expression, and $Q>1$ is positive.
“Zero” never means a zero product. Within a block, every labelled-table/antichain-key pair has unit
weight. Each table contributes 18 classifications, so each block contains 366,264 classifications.
The receipt's immutable `one_vote_per_labelled_count_vector_not_prevalence_or_probability` value is
historical shorthand for equal table weighting in the exhaustive loop, not one scalar observation
per table; the six recorded arrays count all table/key classifications.

| cumulative signed net | 29,496 | 252,816 | 83,952 | 366,264 |
